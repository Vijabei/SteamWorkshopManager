Test build with the feedback on 1.3.1-beta.4 from #1. Tracked in #4.

## Bug fixes

- **List buttons cut off or out of reach** (#5). The row under the mod list - *Check requirements*, *Load installed library*, *Remove selected*, *Clear list*, *Check installed / updates* - was cut off at the bottom, and in a narrow window the buttons disappeared. The row now grows with the buttons and wraps them onto a second line when needed.
- **"Install folder" in the settings looked like an unused duplicate** (#6). It belongs to install mode ("Install for games"); archive mode always uses its own archive folder. The settings now say so.

## Enhancement

- **Collections are archived too** (#7). In archive mode with collection folders, every collection folder - and every `[linked collection]` folder - now holds the collection's own details, the same way each mod folder holds the mod's:
  - `collection_<id>.info` with title, Workshop page, dates, its linked collections and the full description,
  - the preview image and, where the collection has one, the background image of its Workshop page - original files with their upload dates,
  - `Workshop page.url`, with the Workshop link option on.

  This was already prepared in the code: the app fetched these details whenever a collection was added, but only used the title so far.

  Collections are archived before the mods, so running an existing archive again also adds the details to collections archived with beta.4.

## Planned for later

- Preview images in the linked collections dialog (#8).
- A settings page for per-game install folders (#9).

## Before you try it

- This is a pre-release: it is not offered on the stable update channel. Unpack it into a separate folder next to your current installation, or set the update channel to **Beta** in the settings.
- Built and checked automatically; not yet tried by hand on many machines. Feedback welcome in #4.
