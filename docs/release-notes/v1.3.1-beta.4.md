## Archive mode

Archiving now has a mode of its own, switched at the top of the window:

- **Install for games** puts mods into the game's mod folder the way the game expects them - folders named by id, nothing added.
- **Archive** keeps mods for preservation, in its own folder and with its own list. The window turns blue, so the two cannot be confused. Its options are under **Settings → Archive mode** and are all on by default: folders named by title, Workshop dates, the preview image, a link to the Workshop page, the info file inside the mod folder, a folder per collection.

The app asks before archiving into something that looks like a game folder, and before installing into the archive.

**Coming from 1.3.0 or an earlier beta:** if you had any archiving option turned on, the app starts in archive mode, on your current folder, with exactly the options you had. It tells you so once.

## Gallery images (optional, archive mode only)

The other images of a mod's Workshop page can be saved too, as the original files with the uploader's file name and the upload date, in a `Workshop gallery` folder inside each mod folder.

⚠️ This reads every mod's Workshop page - many extra requests for a large collection. Steam may block you for a while. The app then skips the remaining galleries and still installs the mods. Off by default; use at your own risk.

## Also new

- **Linked collections:** when a collection links to others, you choose which to add. With collection folders on, each goes into a `[name]` subfolder.
- **Sharp text** on 1440p and 4K screens - the app no longer gets stretched as a bitmap by Windows.
- **Dark theme:** no more light bands beside the tabs, around the page or at the progress bar.
- **Info file:** with Workshop dates on, it no longer carries the date of your download.
- **Text size:** Settings → Appearance → Text size, in five steps from 90 to 150 %. The whole layout grows with it. Applies after a restart, which the app offers.
- **Settings in tabs** - Downloading, Archive mode, Appearance, Mod library - so nothing is cut off on smaller screens.
- **Messages in the app's own style:** every message and question now follows the theme and the text size, marked in yellow for warnings and red for errors.
- The **Settings** button stands out, and disabled buttons such as Cancel are readable in the dark theme.

## Before you try it

- This is a pre-release: it is not offered on the stable update channel. Unpack it into a separate folder next to your current installation, or set the update channel to **Beta** in the settings.
- Mods that are already installed are updated where they are. For the archive layout, use a new, empty archive folder.
- Built and checked automatically; not yet tried by hand on many machines. Feedback welcome in #4.
